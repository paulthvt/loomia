# Translations

- Add or change English only, in `lib/l10n/app_en.arb`, and give every key an
  `@key` description: it is what the translator reads.
- Other `.arb` files come from Weblate's `weblate/l10n` pull request. Fix a
  translation in Weblate, not in the file.
- Run `flutter gen-l10n` after changing an ARB file. The generated
  `app_localizations*.dart` files are not committed.
- Use placeholders, never string concatenation in the UI.
- Informal register: French is *tu*, never *vous*
  (`test/l10n/french_register_test.dart`). No "recruit", rank or score wording.
